# Movie Data Collection Project

## Overview
This academic project focuses on collecting and organizing movie metadata using Python and external APIs. The dataset supports further data analysis and research.

## Dataset Overview
- Approximately 1,300 movies
- 30 data fields per movie
- Data sources: OMDb API and TMDb API

## Technologies
- Python
- REST APIs
- OMDb API
- TMDb API

## Project Workflow
1. Retrieve movie metadata from external APIs.
2. Extract relevant information such as titles, genres, directors, and ratings.
3. Organize the collected data into a structured dataset.
4. Prepare the dataset for further analysis.
